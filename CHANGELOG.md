# Changelog

What changed in chandratand/ui, newest first. Each entry is dated and names the registry items it affects. Re-pull those items in a Consumer app with `npx shadcn add chandratand/ui/<item> --overwrite`.

**Breaking** marks a change that needs work in the Consumer app after the re-pull (renamed or removed tokens, props or variants, changed markup).

No version tags or changesets: the date is the version.

## 2026-11-23

- **Breaking** (visual), `tokens`: the light-Mode page `background` is now neutral-50 (`#f9fafb`) instead of white. `card` and `popover` stay white, so they read as raised, as they already did in dark Mode. In your app, anything you gave `bg-background` that should stay white (a panel, a filled control) now wants `bg-card`, and anything floating wants `bg-popover`. Re-pull these with them, since they move off `bg-background` the same way:
  - `dialog`, `alert-dialog` and `sheet` now use `bg-popover`, so in dark Mode they are lighter than the page behind the scrim instead of the darkest surface. `sonner`'s cancel button uses `bg-card`.
  - `input`, `textarea`, `select`, `checkbox`, `radio-group`, the outline `button` and the active segmented `tabs` trigger use `bg-card`, so they are white on the page and in a card.
  - `calendar` has no fill of its own and takes the surface it sits on (the Popover in `date-picker`).
  - `field`: `FieldSeparator` with text draws a line either side instead of masking one line with a fill, so it works on any surface.
  - `sidebar`: the `inset` variant's page panel, its hover and current-page fills, the `outline` menu button, `SidebarInput` and the menu action's hover use `bg-card`. The default sidebar stays on `bg-background`.
  - `app-shell`: the "Skip to content" link uses `bg-popover`.
- Docs: the design-system doc explains which surface token a component uses (§4.1, §4.6). Research note on pure black and white in `docs/research/pure-black-and-white.md`.

- Added `login-form`, a Block: `LoginForm`, a sign-in form in a Card with no form library. The email field has `autocomplete="username"` and the password `autocomplete="current-password"`, so browsers and password managers fill them. Errors show and are announced on their Field, focus moves to the first invalid control, and a valid submit calls `onSubmit` with the trimmed email and the password as typed. Sending them is up to the app. Installs `chandratand/ui/button`, `card`, `field` and `input`.

## 2026-11-22

- Added `data-table`, a Block on TanStack Table v9 (`@tanstack/react-table`, a dependency of this Block only). `DataTable` searches every accessor column, filters one column with a Combobox (`filter`), pages with Pagination, and shows a Spinner while `loading` and an Empty state when nothing matches, with a button that clears the search and filter. The line under the table is a polite live region: it announces the count, the page and loading. Updating a row in `data` keeps the current page; a new search or filter goes back to page 1. `invoice-columns.tsx` is an example set of columns with a row actions menu (Dropdown Menu, non-modal). Installs `chandratand/ui/badge`, `button`, `combobox`, `dropdown-menu`, `empty`, `input`, `label`, `pagination`, `spinner` and `table`.
- Added `app-shell`, a Block: `AppShell` gives a Consumer app its frame. The Sidebar collapses to icons (labels move to tooltips) from the header button or Ctrl/⌘ B, the header shows the Breadcrumb (only the current page on a phone), and the page sits in `<main>` behind a "Skip to content" link. Below 768px the Sidebar opens as a Sheet named "Navigation" that closes after navigating. Pass your router's `<Link>` as `linkComponent`; `currentHref` marks the current Sidebar item. Installs `chandratand/ui/breadcrumb`, `separator` and `sidebar`. Its docs page shows it full-page in a frame at `/preview/app-shell`.
- Added `sidebar` and `breadcrumb`. `sidebar` is primary app navigation: `SidebarTrigger` collapses it off canvas or to icons (`collapsible`), reports `aria-expanded`, and Ctrl/⌘ B does the same outside text fields (`keyboardShortcut`, `false` to turn off). A collapsed off-canvas sidebar leaves the tab order. Below 768px it opens as a Sheet named by `label`, and focus returns to the trigger on close. `isActive` marks the current page with `aria-current="page"`, a leading bar and a heavier weight. Menu items take `size` sm/md/lg and `asChild` for router links; `SidebarInset` takes `asChild` when the app already has a `<main>`. Changes from shadcn: no `--sidebar-*` tokens (it uses the semantic ones), variants `ghost`/`outline` and sizes `sm`/`md`/`lg` instead of `default`, no shadows on the `floating` and `inset` variants. Installs `chandratand/ui/button`, `input`, `separator`, `sheet`, `skeleton` and `tooltip`. `breadcrumb` is a navigation landmark labelled "Breadcrumb"; `BreadcrumbPage` marks the current page and `BreadcrumbLink` takes `asChild`.
- Added `form-sheet`, the first Block: `ClientFormSheet`, an add/edit form in a side Sheet with no form library. Errors show and are announced on their Field, focus moves to the first invalid control, and a valid save calls `onSave` and closes the Sheet. Installs `chandratand/ui/button`, `field`, `input`, `sheet` and `textarea`. Block docs pages now list the Components they install.
- Docs site: every Component now has its own page at `/docs/<name>`: `input`, `textarea`, `label`, `select`, `checkbox`, `radio-group`, `switch`, `card`, `badge`, `alert`, `dialog`, `alert-dialog`, `dropdown-menu`, `popover`, `tooltip`, `sonner`, `tabs`, `table`, `separator`, `skeleton` and `avatar` moved over from the demo page. The home page is now an index of every Component and Block page, plus the Tokens. No registry item changed, so nothing to re-pull.
- `accordion`: the trigger's focus ring has room around the header text and no longer covers the divider below it. Item height and text alignment are unchanged.

## 2026-11-17

- `field`: added `FieldTitle`, `FieldSeparator` (installs `chandratand/ui/separator`) and `orientation="responsive"` (set by the width of its `FieldGroup`), matching shadcn. Mark a Field invalid with `invalid` or `data-invalid`. shadcn markup with `htmlFor`/`id` works without `FieldControl`; `FieldLabel` only sets `htmlFor` itself when a `FieldControl` is present. A control's own `id` and `aria-describedby` are kept, and several descriptions or errors in one Field no longer share an id. `pagination`: `PaginationEllipsis` takes `size` like the links. `command`: `CommandInput` shows the standard focus ring.
- Added `pagination` (navigation landmark, current page, labelled previous/next, `asChild` for router links), `spinner` (indeterminate loading status, stops under reduced motion) and `empty` (empty state with title, description and optional action). `pagination` installs `chandratand/ui/button`.
- Added `calendar` (month grid on react-day-picker, installable on its own) and `date-picker` (a single-date field: `calendar` in a `popover` behind a `button` trigger). Locale and display format are props (`locale`, `displayFormat`) defaulting to en-US and `"PPP"`; the trigger takes `size` sm/md/lg.
- Added `field`: Field, FieldLabel, FieldControl, FieldDescription, FieldError, FieldContent, FieldSet, FieldLegend and FieldGroup. `FieldControl` wires the control to its label, hint and error (`aria-describedby`, `aria-invalid`) with no form library; the docs page shows a react-hook-form example that is not shipped.
- Added `progress`, `accordion` and `scroll-area`, each with its own docs page. Accordion's height animation and Progress's fill use the duration tokens, so both stop under reduced motion. A Scroll Area named with `aria-label` or `aria-labelledby` is a focusable region, so keyboard users can scroll it.
- Added `command` (cmdk: inline, or as a command palette with `CommandDialog`, which returns focus to whatever opened it) and `combobox` (search and pick one value from a long list; Command in a Popover, trigger sized sm/md/lg like Select). `combobox` installs `chandratand/ui/command`, `popover` and `button`; `command` installs `chandratand/ui/dialog`.
- Added `sheet`: side panel from any edge (`side` top/right/bottom/left, default right) for secondary content and forms, built on the Radix dialog primitive. Overlay scrim, `shadow-lg`, widths `sm`/`md`/`lg` for side panels, motion collapses under reduced motion. Docs at `/docs/sheet`.
- Docs site: `/docs/<name>` reads its URL param inside `<Suspense>`, so client navigation shows the shared page chrome at once and streams the item content. No registry item changed, so nothing to re-pull.
- Docs site: each Component and Block gets its own page at `/docs/<name>`, generated from `registry.json`. `button` is the first; the rest move over from the demo page next. No registry item changed, so nothing to re-pull.
- **Breaking** · `tokens`: removed the `saas` Brand. Its `[data-brand="saas"]` overrides were identical to the default, so nothing changes visually, but `shadcn add` merges CSS and does not delete it: remove the `[data-brand="saas"]` rules from your `globals.css` by hand, and drop `data-brand="saas"` from `<html>`. The `data-brand` mechanism stays; see `docs/design-system.md` §3 for how to add a Brand.
- `tokens`: added `overlay`, the scrim behind dialogs and sheets.
- Added the rest of the Priority 1 components: `radio-group`, `alert`, `dialog`, `alert-dialog`, `dropdown-menu`, `popover`, `tooltip`, `sonner`, `tabs`, `table`, `separator`, `skeleton`, `avatar`.
- **Breaking** · all items: registry slug renamed from `chandratand/ct-ui` to `chandratand/ui`. Install from `chandratand/ui/<item>`; `registryDependencies` of re-pulled items now point there.
